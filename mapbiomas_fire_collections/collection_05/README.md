# Collection 05 - MapBiomas Fire

This directory contains the scripts and processing workflows for **Collection 05** and **Collection 05.1** of the MapBiomas Fire project.

## 📌 Overview

Collection 05 contains the workflows used for burned-area mapping in Brazil, including data preparation, classification, post-classification processing, generation of derived products, and statistical analysis.

## 📂 Directory Structure

* **[01-pre_classification](./01-pre_classification/)**: Tools for mosaic inspection, training sample collection, scene investigation, and data preparation.
* **[02-classification_algorithms](./02-classification_algorithms/)**: Scripts and algorithms used for burned-area classification.
* **[03-post_classification](./03-post_classification/)**: Post-classification processing, including spatial and temporal refinement, masks, and regional adjustments.
* **[04-subproducts_collection_05](./04-subproducts_collection_05/)**: Scripts for generating derived products from Collection 05, including burned-area metrics and fire scar products.
* **[04-subproducts_collection_05.1](./04-subproducts_collection_05.1/)**: Scripts for generating and updating derived products for Collection 05.1.
* **[05-statistics](./05-statistics/)**: Scripts for calculating areas and exporting statistical outputs for analysis and reporting.

## 🚀 Workflow

1. **Pre-classification**: Prepare mosaics, training samples, input data, and supporting datasets.
2. **Classification**: Run the primary burned-area classification algorithms.
3. **Post-classification**: Refine classification results and apply masks and spatial or temporal adjustments.
4. **Subproducts**: Generate derived products and metrics for Collections 05 and 05.1.
5. **Statistics**: Calculate and export statistics for analysis, reporting, and visualization.
