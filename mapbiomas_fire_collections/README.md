# MapBiomas Fire - Data Collections

This directory centralizes the scripts and processing workflows organized by historical and current MapBiomas Fire collection versions.

## 📂 Contents

The following collections are currently organized in this directory:

- **[collection_04](./collection_04/)**: Contains the complete processing pipeline for Collections 4 and 4.1.
  - Mosaic preprocessing and extraction
  - Classification algorithms
  - Post-processing and LULC 9 / LULC 10 mask filters
  - Generation of derived products and annual/monthly statistics

- **[collection_05](./collection_05/)**: Contains the processing structure and workflows for Collection 5.
  - Data preprocessing
  - Classification workflows
  - Post-processing and filtering
  - Generation of derived products and statistics

## 🎯 Objective

Maintain the development history of the algorithms and ensure the reproducibility of the datasets generated by the MapBiomas Fire working group throughout each stage of the project.

---

For collection-specific instructions and details on how to run the processing workflows, refer to the corresponding collection directory.
